# Nhonga Market — Website/PWA

Esta é a versão web instalável do Nhonga Market. Pode ser publicada em qualquer serviço de hospedagem estática (Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.).

## Como testar
Abra `index.html` no navegador para visualizar a interface. Para que a instalação PWA e o Service Worker funcionem corretamente, publique os arquivos em HTTPS ou use um servidor local.

## Como publicar
Envie todos os arquivos desta pasta para um serviço de hospedagem estática. O arquivo `index.html` é a página principal.

## Importante
Esta versão é uma demonstração/PWA de front-end. Pagamentos M-Pesa/e-Mola, autenticação real, KYC, banco de dados, chat e entregas precisam ser ligados ao backend de produção antes de aceitar transações reais.
